# ИИ-Куратор для образовательной платформы

## О проекте
ИИ-Куратор — это интеллектуальный помощник для студентов образовательных платформ. Проект решает задачи снижения нагрузки на преподавателей и службу поддержки, повышает вовлеченность студентов и персонализирует учебный процесс. 

Бот отвечает на организационные и учебные вопросы, опираясь строго на загруженную базу знаний (RAG), использует метод Сократа для наведения на правильный ответ (не решая задачи за студента) и умеет эскалировать сложные запросы на администратора.

## Ключевые возможности

### Для студента:
*   **Умный чат-бот:** Отвечает на вопросы по материалам курса, расписанию и дедлайнам.
*   **Адаптивность:** ИИ подстраивает тон и сложность ответа в зависимости от уровня студента (начинающий/продвинутый).
*   **Строгие рамки:** Бот никогда не выставляет оценки, не сдвигает дедлайны и не пишет готовый код за студента, всегда ссылаясь на официальную документацию курса.
*   **Связь с поддержкой:** Возможность перевести диалог на живого куратора (эскалация).
*   **Личный кабинет:** Просмотр прогресса, заданий и оценок.

### Для администратора/преподавателя (Полноценная LMS-панель):
*   **Симуляция чата (Impersonation):** Возможность выбрать любого студента из базы и протестировать работу ИИ от его лица (с учетом его уровня подготовки, курса и прогресса).
*   **Управление студентами:** Просмотр списка всех студентов, их текущего прогресса, уровня и доступов.
*   **Управление базой знаний (RAG):** Просмотр загруженных файлов (PDF, DOCX, TXT, JSON) и возможность ручной переиндексации базы знаний прямо из интерфейса.
*   **Аналитика и логирование:** Дашборд с метриками по частым вопросам (распределение по темам) и просмотр истории всех диалогов студентов с ИИ для контроля качества.
*   **Учебная программа:** Просмотр текущего расписания, модулей и активных заданий (интеграция с LMS).
*   **Проверка домашних заданий:** Полноценный интерфейс проверки загруженных студентами файлов, выставление оценок (баллов), написание фидбека и автоматическое обновление прогресса студента.
*   **Система эскалаций (Helpdesk):** Обработка тикетов от студентов, с которыми не справился ИИ. Двусторонний чат поддержки, отслеживание непрочитанных сообщений и закрытие (резолв) тикетов.

## Стек технологий
*   **Интерфейс:** Streamlit
*   **LLM & Оркестрация:** OpenAI API (gpt-4o-mini), LangChain
*   **Векторная база данных (RAG):** ChromaDB (локальная)
*   **Эмбеддинги:** OpenAI (text-embedding-3-small)
*   **Реляционная БД:** SQLite (хранение пользователей, истории чатов, аналитики)

## Установка и запуск

### 1. Предварительные требования
*   Python 3.10 или выше.
*   Ключ OpenAI API.

### 2. Клонирование репозитория
```bash
git clone <url_репозитория>
cd practicaZeroCoder
```

### 3. Создание виртуального окружения и установка зависимостей
```bash
python -m venv venv
source venv/Scripts/activate  # Для Windows
# source venv/bin/activate    # Для Linux/Mac
pip install -r requirements.txt
```

### 4. Настройка переменных окружения
Создайте файл `.env` в корне проекта (или скопируйте из `.env.example`) и добавьте ваш API ключ:
```env
OPENAI_API_KEY=sk-вашки-ключ
LLM_MODEL=gpt-4o-mini
LLM_TEMPERATURE=0.2
EMBEDDING_MODEL=text-embedding-3-small
```

### 5. Запуск приложения
```bash
streamlit run app.py
```
При первом запуске система автоматически создаст необходимые таблицы в SQLite и проиндексирует базу знаний из папки `data/kb/` в ChromaDB.

## Структура проекта
```text
.
├── app.py                 # Главный файл Streamlit-приложения
├── src/                   # Исходный код логики
│   ├── agent.py           # Настройка LangChain, системный промпт
│   ├── rag.py             # Логика загрузки документов и векторного поиска
│   ├── db.py              # Взаимодействие с SQLite
│   ├── config.py          # Глобальные настройки и пути
│   ├── logger.py          # Настройка логирования
│   └── ui/                # Компоненты интерфейса Streamlit
├── data/                  # Данные приложения
│   ├── kb/                # Исходные файлы базы знаний (PDF, DOCX, TXT, JSON)
│   ├── lms/               # Имитация данных LMS (расписание, задания)
│   └── analytics/         # Логи и выгрузки
├── docs/                  # Подробная документация
│   └── architecture.md    # Описание архитектуры и логики работы
├── chroma_db/             # Локальное хранилище векторной БД (генерируется автоматически)
├── requirements.txt       # Зависимости Python
└── .env                   # Переменные окружения (не коммитить!)
```
