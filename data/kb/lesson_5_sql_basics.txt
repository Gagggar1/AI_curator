Урок 5: Основы работы с базами данных (SQL)
В этом уроке мы изучим базовые SQL-запросы для работы с реляционными базами данных.

1. SELECT - выборка данных. 
Пример: SELECT * FROM users WHERE age > 18;

2. INSERT - вставка данных. 
Пример: INSERT INTO users (name, age) VALUES ('Ivan', 25);

3. UPDATE - обновление существующих данных. 
Пример: UPDATE users SET age = 26 WHERE name = 'Ivan';

4. DELETE - удаление данных. 
Пример: DELETE FROM users WHERE id = 1;

ВАЖНО: Всегда используйте параметризованные запросы в Python (через модули sqlite3, psycopg2 или SQLAlchemy), чтобы избежать уязвимостей типа SQL-инъекций! Никогда не склеивайте строки (f-strings) при формировании SQL-запросов.
